METHOD 01

Programmed I/O

The CPU repeatedly polls the device status register. When the device is ready, the CPU reads the data and writes it to memory.

CPU role: actively checks status and moves data.

METHOD 02

Interrupt-Driven I/O

The CPU starts an I/O request and can perform other work. The device interrupts the CPU when it is ready, and the interrupt service routine handles the transfer.

CPU role: responds when interrupted.

METHOD 03

Direct Memory Access (DMA)

The CPU configures the DMA controller. The controller transfers data directly between the I/O device and memory, then notifies the CPU when finished.

CPU role: sets up the transfer and handles completion.

Step-by-step flow

  1. Choose the transfer method and configure the device, data value, and memory address.
  2. Start the simulation with Next Step or run all stages with Run Cycle.
  3. Observe how the selected method requests, transfers, and completes the data movement.
  4. Read the final result showing the value written to the chosen memory address.
⌘   03 / PROGRAMMING LANGUAGE

Technologies Used

This project is implemented as a standalone webpage using HTML for structure, CSS for styling, and JavaScript for the interactive simulation. It runs locally in a modern browser and does not require a backend or database.

HTML — page structure, navigation, inputs, output sections CSS — responsive layout, dark theme, cards, progress indicators JavaScript — transfer-method logic, step-by-step state, validation Core simulation logic (simplified): 1. Read selected transfer method and input data. 2. Validate that the data value is between 0 and 255. 3. Show request / transfer / completion stages. 4. Simulate writing the value to the selected memory address. 5. Display the result and CPU involvement for that method.

Learning outcomes

  • Differentiate polling, interrupt-based transfer, and DMA.
  • Trace data movement from an I/O device to main memory.
  • Understand how the transfer method affects CPU involvement.
  • Use configurable inputs to explore different simulation cases.
✓   04 / TESTING & RESULTS

Testing Procedure

  1. Open the HTML file in a modern browser.
  2. Select an I/O method and enter a data value from 0 to 255.
  3. Click Next Step repeatedly to inspect each stage.
  4. Use Run Cycle to complete all stages automatically.
  5. Change the input or method and reset to test another case.
